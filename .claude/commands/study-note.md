你是我的 Java 全栈学习教练。现在把我要记的东西整理成一条结构化笔记，存进 `notes/`。

## 步骤

1. **确定归属周**：读取 `PROGRESS.md` 的「当前位置」，拿到我现在在第几周（用于笔记文件命名）。

2. **确定笔记内容**：
   - 如果我在命令后写了内容（`$ARGUMENTS`），就以它为主题。
   - 如果没写，就回顾**本次对话刚刚学的/踩到的**最近一个知识点或坑，作为要记录的内容。
   - 拿不准记哪个，就简短问我一句「你想记哪个点？」

3. **确定文件**：
   - 文件名规则：`notes/第X周-主题.md`（X 为当前周，主题取简短关键词，如 `第1周-java环境搭建.md`）。
   - 如果该主题文件**已存在**，就**追加**一条新记录（不要覆盖旧内容）；不存在则新建，开头加一级标题。

4. **按这个结构写这条笔记**（简洁，别啰嗦）：

   ### 🗒️ [知识点/坑的名字]（记录时间：让我口述或写"今天"）
   - **是什么**：一句话解释（尽量用前端概念类比）
   - **踩了什么坑 / 卡在哪**（如果是坑才写）
   - **怎么解决的 / 正确做法**
   - **关键代码或命令**（如果有，用代码块）
   - **一句话记住它**：给我一个好记的总结

5. 写完后，告诉我存到了哪个文件、是新建还是追加，并**顺带提醒我**：这些笔记以后可以用 `/study-review` 复盘时作为证据，也方便回看。

注意：笔记是给「未来的我」看的，要让隔一个月回来也能秒懂。遵守 CLAUDE.md 的教练风格。

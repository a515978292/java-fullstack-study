### 🗒️ 新建 IntelliJ 项目「无模块」导致代码跑不了（记录时间：今天 2026-07-13）

- **是什么**：IntelliJ 里，代码必须挂在一个「模块（Module）」上才能运行——模块负责组织代码、绑定 JDK。模块之于 IntelliJ 项目，有点像 `package.json` 之于前端项目：没有它，工具就不知道「这坨代码算不算数、用什么跑」。

- **踩了什么坑 / 卡在哪**：用「IntelliJ 构建系统」新建项目后，模块没被正确生成，连锁反应一路卡：
  - 「项目结构 → 模块」里显示「没有要显示的内容」（= 一个模块都没有）
  - SDK 是红色的 `<无 SDK>`（项目没绑 JDK 引擎）
  - `src` 右键没有「将目录标记为源代码根目录」
  - `main` 方法左边**不出现绿色运行三角 ▶️**，顶部运行按钮也是灰的
  - 顶部「运行」菜单里只有「编辑配置…」，没有「运行 'Main'」

- **怎么解决的 / 正确做法**：**删掉重建，新建时「构建系统」改选 `Maven`**。Maven 会用标准结构自动把模块、源码目录、JDK 全配好，一把跑通。（中途也试过手动在「项目结构」里补 SDK，能补上 SDK 但模块仍是空的，治标不治本。）

- **关键排查点**：跑不了时，第一件事去 **文件 → 项目结构（`⌘;`）→ 模块**，看是不是空的；再看「项目」页 SDK 是不是 `<无 SDK>`。

- **一句话记住它**：**跑不了先查「有没有模块 + 有没有 SDK」；新建项目优先选 Maven，省一堆坑。**

### 🗒️ 一串前端 → Java 的对照（记录时间：今天 2026-07-13）

- JDK ≈ Node.js（没有它 `.java` 跑不起来）
- `java -version` ≈ `node -v`
- `System.out.println()` ≈ `console.log()`
- `main` 方法 ≈ 程序入口（类比 `index.js` 最先执行的那段）
- 编译再运行：`javac Main.java`（≈ `tsc`）→ `java Main`（≈ `node index.js`）
- `for (int i = 1; i <= 5; i++)` 和 JS 的 for 几乎一模一样

- **一句话记住它**：**Java 不是全新世界，大量概念能从前端平移；真正新的只有 Java 语法、Spring、SQL 三样。**

### 🗒️ 变量与类型（记录时间：2026-07-14）

- **是什么**：Java 是强类型语言，声明变量必须写清类型，思路和 TypeScript 一样，只是**类型写的位置不同**。
  - TS：`let age: number = 25`（类型在**后**）
  - Java：`int age = 25;`（类型在**前**）
- **三个常用类型**：
  ```java
  int age = 25;          // 整数
  String name = "张腾";   // 文字，注意 String 首字母大写（不是 js 的小写 string）
  boolean ok = true;     // 真/假
  ```
- **两个必踩的细节**：
  - 每条语句**结尾必须加分号 `;`**（不像 JS 可有可无）
  - `String` 大写 S，写成小写 `string` 会报错
- **一句话记住它**：**Java 声明变量「先说类型、再说名字」，行尾加分号，String 大写。**

### 🗒️ 字符串拼接 & println vs printf（记录时间：2026-07-14）

- **拼接**：和 JS 一样用 `+`：`"我叫" + name + "，今年" + age + "岁"`
- **数字自动转文字**：`+` 只要有一边是文字（String），另一边的数字就被自动转成文字再拼。
  - 所以 `"我今年" + age`（age=30）→ Java 把 30 转成 `"30"` → 得到 `"我今年30"`
- **print / printf vs println**：
  - `println` = 打印**并换行**（ln = line）
  - `print` / `printf` = 打印**不换行** → 两句会黏在一行
- **一句话记住它**：**拼接全用 `+`，一边是文字数字就被转成文字；要换行用 `println`。**

### 🗒️ 类与对象（第 1 周最重要的概念）（记录时间：2026-07-14）

- **是什么**：
  - **类 = 图纸**（模板，本身没有具体值），定义「有哪些字段、有哪些行为」
  - **对象 = 按图纸造出来的实物**（有具体值），用 `new` 创建
  - 前端类比：类像组件的 props 类型定义 `{name: string; age: number}`，对象像 `<Person name="张腾" age={30} />` 真正传了值那次
- **硬规矩**：一个 public 类 = 一个同名文件。`public class Person` → 必须放在 `Person.java` 里，且和用它的类同一个 package。
- **完整例子**：
  ```java
  // Person.java —— 图纸
  public class Person {
      String name;   // 字段：只声明不赋值（值等造对象时再填）
      int age;
      public void introduce() {                 // 方法：void = 不返回值
          System.out.println("我叫" + name + "今年" + age + "岁");
      }
  }
  ```
  ```java
  // Main.java 里 —— 造实物并使用
  Person p = new Person();   // new = 按图纸造一个对象
  p.name = "张腾";           // 用 . 访问字段（同 JS 的 obj.name）
  p.age = 30;
  p.introduce();             // 用 . 调方法（同 JS 的 obj.method()）
  ```
- **关键理解**：`introduce()` 里的 `name`/`age`，运行时取的是**当前这个对象**的值。再 `new` 一个 `p2` 填别的值，`p2.introduce()` 就打印 p2 的值——同一张图纸，每个对象各有各的值。
- **一句话记住它**：**类是图纸（无值），对象是实物（有值），`new` 负责按图纸造实物；方法里的字段取「当前对象」的值。**

### 🗒️ 踩过的两个 bug（记录时间：2026-07-14）

- **① `println` 里用逗号**：写成 `println("我叫" + name , "今年" + age)` → 报错。
  - 原因：JS 的 `console.log` 能用逗号传多个参数，但 Java 的 `println` **只收一个字符串**，必须全用 `+` 拼成一整串。
- **② 变量名复制没改**：把 `"今年" + age` 写成了 `"今年" + name` → 输出年龄处成了名字。
  - 教训：**拼接完从头念一遍**，肉眼查这种「复制粘贴忘改」的 bug。
- **一句话记住它**：**Java 的 println 只收一个字符串（别用逗号）；拼完念一遍防手滑。**

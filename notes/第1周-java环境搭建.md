### 🗒️ 新建 IntelliJ 项目「无模块」导致代码跑不了（记录时间：今天 2026-07-13）

- **是什么**：IntelliJ 里，代码必须挂在一个「模块（Module）」上才能运行——模块负责组织代码、绑定 JDK。模块之于 IntelliJ 项目，有点像 `package.json` 之于前端项目：没有它，工具就不知道「这坨代码算不算数、用什么跑」。

- **踩了什么坑 / 卡在哪**：用「IntelliJ 构建系统」新建项目后，模块没被正确生成，连锁反应一路卡：
  - 「项目结构 → 模块」里显示「没有要显示的内容」（= 一个模块都没有）
  - SDK 是红色的 `<无 SDK>`（项目没绑 JDK 引擎）
  - `src` 右键没有「将目录标记为源代码根目录」
  - `main` 方法左边**不出现绿色运行三角 ▶️**，顶部运行按钮也是灰的
  - 顶部「运行」菜单里只有「编辑配置…」，没有「运行 'Main'」

- **怎么解决的 / 正确做法**：**删掉重建，新建时「构建系统」改选 `Maven`**。Maven 会用标准结构自动把模块、源码目录、JDK 全配好，一把跑通。（中途也试过手动在「项目结构」里补 SDK，能补上 SDK 但模块仍是空的，治标不治本。）

- **关键排查点**：跑不了时，第一件事去 **文件 → 项目结构（`⌘;`）→ 模块**，看是不是空的；再看「项目」页 SDK 是不是 `<无 SDK>`。

- **一句话记住它**：**跑不了先查「有没有模块 + 有没有 SDK」；新建项目优先选 Maven，省一堆坑。**

### 🗒️ 一串前端 → Java 的对照（记录时间：今天 2026-07-13）

- JDK ≈ Node.js（没有它 `.java` 跑不起来）
- `java -version` ≈ `node -v`
- `System.out.println()` ≈ `console.log()`
- `main` 方法 ≈ 程序入口（类比 `index.js` 最先执行的那段）
- 编译再运行：`javac Main.java`（≈ `tsc`）→ `java Main`（≈ `node index.js`）
- `for (int i = 1; i <= 5; i++)` 和 JS 的 for 几乎一模一样

- **一句话记住它**：**Java 不是全新世界，大量概念能从前端平移；真正新的只有 Java 语法、Spring、SQL 三样。**
